# How to Download Files from GitHub

You can download the files **one by one** by following these steps:

1. Open the folder and click the file you want to download.
2. Click the **Download** icon (⬇️) near the top-right of the file preview.
3. If you do not see the Download icon, click **More file actions** (⋯) → **Download** (⬇️).
4. Repeat these steps for each file.
